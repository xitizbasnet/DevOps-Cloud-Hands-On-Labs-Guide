# How to Use This Guide

> [!IMPORTANT]
> This guide is designed as a **hands-on lab workbook**. The labs are progressive and should be completed in sequence to build foundational and advanced cloud and DevOps skills.

## Overview

This guide is structured as a **hands-on lab workbook** covering:

* **51 progressive labs**
* **8 capstone projects**

The workbook spans the following technologies and platforms:

* ☁️ AWS
* ☁️ Azure
* 🐳 Docker
* ☸️ Kubernetes
* ⚙️ Ansible
* 🌍 Terraform
* 🔄 CI/CD
* 📊 Observability

Each lab contains the following components:

* 🎯 **Objective**
* 📋 **Prerequisites**
* 🛠️ **Step-by-step tasks**
* 💡 **Best Practice Tips**

## Prerequisites

> [!NOTE]
> The following baseline knowledge and environment are assumed before starting this guide.

* ✅ You already have an **AWS Free Tier** account configured in the **ap-south-1** region.
* ✅ You have basic familiarity and working comfort with **Linux**.
* ✅ **Git** is installed and ready to use.

## Learning Path

> [!TIP]
> The labs are intentionally designed to build upon one another.

Complete the labs **in order**, as each lab progressively introduces new concepts and skills that are used in subsequent exercises.
